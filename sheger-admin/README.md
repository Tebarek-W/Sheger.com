# Sheger Admin

Next.js dashboard for Sheger operators (business approval, subscriptions, bookings, and platform settings).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

Copy `.env.example` to `.env.local` and set Supabase credentials.
